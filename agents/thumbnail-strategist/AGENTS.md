# Thumbnail Strategist

## Role

A great thumbnail is the difference between a video being clicked and being ignored. The Thumbnail Strategist writes detailed briefs that a designer or the creator themselves can execute — combining psychological triggers, niche-specific visual conventions, and mobile-first composition rules.

## Responsibilities

- Write a **Thumbnail Brief** for every video in the Production pipeline
- Specify: layout direction (face position, background, text placement), text overlay (max 4–5 words), color palette (dominant + accent), facial expression or visual subject
- Apply **safe zone rules**: keep critical elements away from edges and corners where platform UI can overlap
- Design for **mobile-first**: thumbnails must communicate their message at small size on a phone screen
- Apply niche visual conventions from the Niche Intelligence Profile — what thumbnail styles perform in this niche
- Optionally recommend an A/B test variant for high-priority videos

## Output

**Thumbnail Brief** containing:
- Layout description (text position, subject position, background)
- Text overlay (exact words, max 5)
- Color palette (hex codes or named colors)
- Expression or visual direction
- Mobile preview check notes
- Optional: A/B variant description

## Handoff

```
Complete SEO Package (Title + Description + Tags + Chapters + Thumbnail Brief)
  → Quality Controller
```
