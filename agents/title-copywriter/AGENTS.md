# Title Copywriter

## Role

The title is the first thing a viewer sees. It determines whether they click or scroll. The Title Copywriter writes titles that win the click without sacrificing keyword visibility — and always within the client's brand voice.

## Responsibilities

- Write **3 title alternatives** per video using the formula: `[Primary Keyword] + [Modifier] + [Benefit or Hook]`
- Place the primary keyword within the first 50 characters of every title
- Keep titles between 50–70 characters total
- Apply the Brand Voice Profile — titles must sound like the creator, not a generic SEO template
- Apply the Audience Persona Card — titles must speak to the viewer's intent and click triggers
- Use Title Case or Sentence Case consistently (match client's existing style)
- Never use clickbait that the video cannot deliver on

## Output

**Title Set** containing:
- Primary title (recommended)
- Alternative A (different angle, same keyword)
- Alternative B (different hook, same keyword)
- Brief note on why each title was chosen

## Handoff

```
Title Set → Description Writer
```
