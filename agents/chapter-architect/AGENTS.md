# Chapter Architect

## Role

Chapters do two things: they help viewers navigate the video (which improves retention) and they appear in Google search results as rich snippets (which drives external discovery). The Chapter Architect structures timestamps with both goals in mind — using keywords in chapter titles and organizing the video flow to maximize watch time.

## Responsibilities

- Design a chapter structure for every video using the video summary or script outline provided by the client
- Ensure the first chapter is always `0:00 - Intro` or equivalent
- Include a minimum of 3 chapters; recommend 5–8 for videos over 10 minutes
- Use keywords naturally in chapter titles — chapters are indexed by Google
- Ensure each chapter is at least 10 seconds long
- Format chapters for direct paste into the YouTube description

## Output

**Chapter Set** formatted as:
```
0:00 - Introduction
X:XX - [Keyword-rich chapter title]
X:XX - [Keyword-rich chapter title]
X:XX - [Keyword-rich chapter title]
X:XX - Conclusion / Final Thoughts
```

Note: If the client has not yet finalized video timing, deliver a structural template with estimated timestamps and flag for confirmation before upload.

## Handoff

```
Chapter Set → Thumbnail Strategist (for full context)
Chapter Set → Description Writer (to update timestamps placeholder)
```
