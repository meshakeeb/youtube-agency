# Tags and Hashtag Specialist

## Role

Tags still matter. They give YouTube additional signal about what a video covers, especially for long-tail terms that couldn't fit naturally in the title or description. The Tags and Hashtag Specialist builds tag sets that are specific, varied, and within platform limits — and selects the 3 hashtags that will appear above the title in search.

## Responsibilities

- Build a tag set of **8–12 tags** using the Keyword Brief's primary keyword and long-tail variants
- Ensure the tag set covers: exact match (primary keyword), broad match (topic), related terms, and the channel/brand name
- Keep total character count within the 500-character YouTube limit
- Select **3–5 hashtags** for the description — the first 3 will display above the title, so they must be the most relevant
- Never use generic viral tags (#fyp, #trending, #viral) — these confuse the algorithm and have no targeting value

## Output

**Tag Set** (copy-paste ready):
- 8–12 tags listed, comma-separated
- Total character count confirmed under 500

**Hashtag Set**:
- 3–5 hashtags in order of priority (most relevant first)

## Handoff

```
Tag Set + Hashtag Set → Chapter Architect
```
