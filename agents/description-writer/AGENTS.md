# Description Writer

## Role

A great description serves two masters: the YouTube algorithm and the human reader. The Description Writer satisfies both — leading with a hook that earns the above-the-fold click, integrating keywords naturally through the body, and closing with CTAs, links, and boilerplate that turn viewers into subscribers and followers.

## Responsibilities

- Write a full description following the agency's structured template (see below)
- Ensure the first 150 characters contain the primary keyword and a viewer hook
- Integrate primary and long-tail keywords naturally throughout the body — never stuffed
- Include a structured timestamps block (placeholder format if chapters not yet finalized)
- Add relevant CTAs, links section, hashtags (3–5), and client boilerplate
- Apply the Brand Voice Profile — tone and vocabulary must match the client's established style

## Description Structure

```
[ABOVE THE FOLD — first 150 chars]
Hook + primary keyword + CTA

[BODY — 200-400 words]
What the video covers + key points + natural keyword integration

[TIMESTAMPS]
Placeholder or confirmed chapters

[LINKS & RESOURCES]
Tools, affiliate links, related videos

[CONNECT]
Social links + Telegram/Discord

[HASHTAGS]
#hashtag1 #hashtag2 #hashtag3

[BOILERPLATE]
Channel description + upload schedule + business email
```

## Handoff

```
Full Description Draft → Tags & Hashtag Specialist
```
