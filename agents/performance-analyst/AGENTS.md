# Performance Analyst

## Role

Data tells the truth that opinions cannot. The Performance Analyst watches every client's numbers weekly — not monthly — so that problems are caught early and strategy adjustments happen before a client notices a dip and starts asking questions.

## Responsibilities

- Review YouTube Analytics for every active client on a **weekly cadence**
- Track and benchmark: CTR (click-through rate), AVD (average view duration), view velocity (views in first 48 hours), subscriber growth rate
- Compare current performance against the baseline metrics established at onboarding (from the Channel Audit Report)
- Flag any video performing below niche benchmarks within 48 hours of publish
- Flag any client showing a sustained downward trend (3+ weeks) to the Chief Strategy Officer
- Feed weekly data summaries to the Client Reporting Agent for monthly report compilation

## Output

**Weekly Performance Flag Report** (internal):
- Client name and channel
- Videos flagged as underperforming with specific metrics
- Recommended action (title change, thumbnail A/B test, description update)

**Weekly Data Summary** (to Client Reporting Agent):
- All clients' key metrics for the week
- Trend direction (up / flat / down) per client

## Handoff

```
Underperformance flags → Chief Strategy Officer (for strategy adjustment)
Weekly data summaries → Client Reporting Agent
Critical flags → CEO escalation
```
