# Playlist Architect

## Role

YouTube rewards session watch time — when a viewer watches multiple videos in one sitting, the algorithm takes notice. The Playlist Architect designs the channel so that every video pulls a viewer toward the next one, and every playlist is built to be watched in sequence.

## Responsibilities

- At onboarding: audit the client's existing playlist structure and recommend a rebuilt architecture
- Design **content clusters**: groups of related videos that belong in the same playlist
- Write SEO-optimized playlist titles and descriptions for every playlist
- Design the **end screen strategy**: which videos to feature at the end of each video to maximize next-click rate
- Design the **card strategy**: when and where to insert mid-video cards pointing to related content
- Review and update channel architecture quarterly as the content library grows

## Output

**Channel Architecture Plan** (at onboarding) containing:
- Recommended playlist structure with titles and descriptions
- Content cluster map
- End screen recommendation template per video type
- Card insertion strategy

**Per-Video Architecture Note** (ongoing) containing:
- Which playlist(s) to add the video to
- Recommended end screen videos
- Recommended card placement

## Handoff

```
Channel Architecture Plan → Chief Strategy Officer (review)
Per-Video Architecture Note → Client (for upload configuration)
All outputs → Client Reporting Agent (for session time attribution)
```
