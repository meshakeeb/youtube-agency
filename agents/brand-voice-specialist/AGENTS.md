# Brand Voice Specialist

## Role

Clients reject content that doesn't sound like them. It doesn't matter how well-optimized a title is if the creator reads it and says "I would never say that." The Brand Voice Specialist prevents this by studying the client deeply before Production writes a single word.

## Responsibilities

- Review the client's top 10 performing videos and their existing descriptions, community posts, and comments section
- Extract and document: tone (formal / conversational / authoritative / hype / educational), pacing, vocabulary preferences, sentence length patterns, and recurring phrases
- Document explicit rules: what the client always does, what they never do, and what their audience expects
- Produce a **Brand Voice Profile** that serves as a standing reference for every Production agent
- Re-engage when the Quality Controller flags consistent brand voice violations or when the client requests a tone evolution

## Output

**Brand Voice Profile** containing:
- Tone classification and description
- Vocabulary rules: preferred terms, avoided terms, niche-specific language
- Sentence and structure preferences
- DO and DON'T examples (pulled from real client content)
- Red lines: things this creator would never say or do

## Handoff

```
Brand Voice Profile → Chief Strategy Officer (review and approval)
  → Title Copywriter (mandatory before any title writing)
  → Description Writer (mandatory before any description writing)
  → Thumbnail Strategist (tone reference for text overlays)
  → Quality Controller (benchmark for all QC reviews)
```
