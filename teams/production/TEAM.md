# Production Team

## Purpose

The Production Team is the agency's highest-volume operation. For every video a client publishes, this team produces a complete, niche-specific, brand-voice-approved SEO package. Speed and quality must coexist — which is why every agent in this team has a narrow, defined job and a clear handoff to the next.

## Responsibilities

- Receive video topic and niche intelligence inputs from Intelligence Team
- Research and confirm the **primary keyword and long-tail variants** for the video
- Write **3 title alternatives** per video, optimized for CTR and keyword placement
- Write a **full SEO description** (200–500 words) with keyword integration, timestamps, CTAs, and boilerplate
- Generate a **tag set** (8–12 tags, within 500-character limit) and **3–5 hashtags**
- Architect **video chapters** with keyword-rich titles, starting at 0:00
- Deliver a **thumbnail brief** with layout, text overlay, color, and expression direction
- Pass the complete package to Quality Control before delivery

## Production Pipeline (Strict Order)

```
Keyword Researcher
  → Title Copywriter
    → Description Writer
      → Tags & Hashtag Specialist
        → Chapter Architect
          → Thumbnail Strategist
            → [hand off to Quality Controller]
```

Each agent only begins when the previous agent's output is confirmed. No skipping steps.

## Inputs Required Before Starting

- Niche Intelligence Profile (from Intelligence Team)
- Audience Persona Card (from Intelligence Team)
- Brand Voice Profile (from Onboarding Team)
- Video topic or script summary (from client)

## Team Members

| Agent | Role | Takes From | Passes To |
|---|---|---|---|
| Keyword Researcher | Finds primary keyword and variants | Intelligence Team | Title Copywriter |
| Title Copywriter | Writes 3 optimized title options | Keyword Researcher | Description Writer |
| Description Writer | Writes full SEO description | Title + Keywords | Tags Specialist |
| Tags & Hashtag Specialist | Builds tag set and hashtags | Description | Chapter Architect |
| Chapter Architect | Structures timestamps with keywords | All above | Thumbnail Strategist |
| Thumbnail Strategist | Writes thumbnail brief | All above | Quality Controller |
