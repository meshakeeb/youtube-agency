# YouTube Description Writing

## When to Use

Activate this skill after the Title Set has been produced. Third step in the Production pipeline.

## Inputs Required

- Keyword Brief (primary keyword, long-tail variants, intent type)
- Title Set (primary title confirmed)
- Brand Voice Profile (tone, vocabulary, ALWAYS/NEVER rules)
- Audience Persona Card (language rules, formality level)
- Video summary or outline (from client — what the video actually covers)

## Description Architecture

YouTube shows the first 150–200 characters before the "Show more" cutoff. Everything after that requires a click to see. Design the description in two distinct zones:

**Zone 1 — Above the Fold (first 150 characters)**: This is the most valuable real estate. Must include the primary keyword and a hook that gives the viewer a reason to watch or read more.

**Zone 2 — Below the Fold (everything after)**: Algorithm food + viewer utility. Keyword integration, timestamps, links, hashtags, boilerplate.

## Keyword Integration Rules

### Primary Keyword
- Must appear in the first 150 characters (above the fold)
- Should appear 2–3 times total across the full description
- Must read naturally — never forced

### Long-Tail Variants
- Integrate 3–4 long-tail variants from the Keyword Brief
- One per bullet point in the "What this video covers" section
- Must read as natural English, not keyword strings

### What Keyword Stuffing Looks Like (NEVER DO THIS)
```
❌ "In this forex trading video we cover forex trading tips for forex traders
   who want to learn forex trading strategies for forex..."
```

### What Natural Integration Looks Like
```
✅ "In this video, I walk through the exact price action setups I use for
   day trading forex — the ones that have kept me consistently profitable
   even in choppy markets."
```

## Brand Voice Application

The description tone must match the Brand Voice Profile:
- Use the vocabulary from the "power words" and "recurring phrases" list
- Apply ALWAYS rules: if the creator always uses "we" — use "we"
- Apply NEVER rules: if the creator never uses corporate jargon — avoid it
- Match the creator's sentence length patterns
- Match their CTA phrasing style exactly

## Above-the-Fold Examples

**Trading niche (energetic, direct)**:
```
Master high-probability price action setups that consistently beat the market.
Watch this before your next trade. 📈
```

**Fitness niche (motivational, peer-to-peer)**:
```
These 5 HIIT workouts actually work — no equipment, no excuses, just results.
Let's get into it.
```

**Tech review (analytical, authoritative)**:
```
After 6 months with the iPhone 16 Pro, here's my completely honest take —
the good, the bad, and what Apple won't tell you.
```
