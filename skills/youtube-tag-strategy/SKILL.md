# YouTube Tag Strategy

## When to Use

Activate this skill after the Description Draft has been produced. Fourth step in the Production pipeline.

## Inputs Required

- Keyword Brief (primary keyword and all long-tail variants)
- Description Draft (to cross-check keyword consistency)
- Brand Voice Profile (channel/brand name for brand tag)
- Niche Intelligence Profile (niche vocabulary for related term tags)

## Why Tags Still Matter

YouTube uses tags as a secondary relevance signal — particularly for spelling variants, related terms, and context that couldn't fit naturally in the title or description. Tags also help YouTube understand which other videos to recommend alongside the client's video. They are not the primary ranking factor, but a well-built tag set reinforces the full SEO package.

## Tag Architecture

Build the tag set in four layers:

### Layer 1 — Exact Match (1–2 tags)
The primary keyword exactly as confirmed in the Keyword Brief.
- These tell YouTube precisely what the video is about.
- Example: if primary keyword is "price action trading", first tag is "price action trading"

### Layer 2 — Long-Tail Variants (3–4 tags)
Select the best 3–4 long-tail variants from the Keyword Brief.
- Choose variants most likely to have independent search volume
- Example: "price action trading for beginners", "price action setups 2025"

### Layer 3 — Broad Topic Tags (2–3 tags)
The parent topic and adjacent topics that describe the video's wider context.
- These help YouTube surface the video in "related videos" recommendations
- Example: "forex trading", "day trading strategies", "technical analysis"

### Layer 4 — Brand Tag (1 tag)
The client's channel name or brand name.
- Helps cluster the client's videos together in YouTube's recommendation graph
- Example: "youtube trading"

## Hashtag Selection

Hashtags appear in the description and the first 3 display above the video title in search results. This means the first 3 hashtags are visible real estate — use them carefully.

### Hashtag Rules
- Use 3–5 hashtags maximum (more than 15 causes YouTube to ignore all hashtags)
- First 3 hashtags are the most important — they display above the title
- Hashtags must be single-word or compound (no spaces): #PriceAction, #ForexTrading
- Must be directly relevant to the video content
- Never use: #fyp, #viral, #trending, #foryou — YouTube is not TikTok

### Hashtag Selection Process
1. **Hashtag 1**: the primary keyword in hashtag format (broadest relevant term)
2. **Hashtag 2**: the niche or sub-niche hashtag
3. **Hashtag 3**: the topic angle or content type
4. **Hashtag 4–5 (optional)**: related audience hashtag or brand hashtag

Example for a forex price action video:
```
#PriceAction #ForexTrading #DayTrading #TradingStrategy #YouTubeTrading
```

## Character Count Management

YouTube tag limit: 500 characters total (including commas and spaces).

Budget accordingly:
- Primary keyword: ~20–30 chars
- 3–4 long-tail variants: ~30–50 chars each
- 2–3 broad topics: ~15–25 chars each
- 1 brand tag: ~10–20 chars
- Target total: 400–480 characters (leave buffer)

Never pad to hit 500 — irrelevant filler tags hurt more than help.

## Tags That Are Prohibited

Never use:
- Competitor channel names (against YouTube's terms of service)
- Misleading tags that don't match the video content
- Generic tags with no targeting value: "youtube", "video", "watch"
- Viral/trending tags disconnected from content: "#fyp", "#shorts" on long-form

```
TAG AND HASHTAG SET
Client: [Name]
Video: [Primary Title]
Primary Keyword: [keyword]
Date: [YYYY-MM-DD]

TAGS (copy-paste ready — comma separated):
[tag1], [tag2], [tag3], [tag4], [tag5], [tag6], [tag7], [tag8], [tag9], [tag10]

Tag count: [X tags]
Character count: [XXX / 500 characters]

TAG LAYER BREAKDOWN:
Exact match: [tag(s)]
Long-tail variants: [tag(s)]
Broad topics: [tag(s)]
Brand: [tag]

HASHTAGS (in priority order — paste into description):
#Hashtag1 #Hashtag2 #Hashtag3 #Hashtag4 #Hashtag5

Hashtag 1 (above title): #[most relevant]
Hashtag 2 (above title): #[niche]
Hashtag 3 (above title): #[topic angle]
```

## Handoff

Tag Set + Hashtag Set → Chapter Architect

## Quality Check

- [ ] 8–12 tags total
- [ ] All four layers represented
- [ ] Character count confirmed under 500
- [ ] First 3 hashtags are the strongest relevance signals
- [ ] No prohibited tags included
- [ ] Brand tag included
