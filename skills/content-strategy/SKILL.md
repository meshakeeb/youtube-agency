# Content Strategy

## When to Use

Activate this skill when:
- A new client's onboarding is complete and a 90-day content strategy is needed
- Monthly strategy review signals that a current approach is not working
- A client's niche shifts or they request a new content direction
- The Performance Analyst flags sustained underperformance requiring strategic adjustment

## Inputs Required

- Completed onboarding package (Niche Intelligence Profile, Audience Persona Card, Brand Voice Profile, Channel Audit Report)
- Competitor Gap Report (top 20 keyword opportunities)
- Client's content goals and constraints (upload frequency, video length, production capacity)
- Performance data for existing clients (from Performance Analyst)

## 90-Day Content Strategy Design

The first strategy for a new client covers 90 days. It establishes the content mix, keyword targets, and upload cadence. It should be data-informed, not opinionated.

### Phase 1 — Foundation (Days 1–30)
**Goal**: establish the channel's SEO baseline and prove the agency's value quickly.

Focus:
- Target the top 5 keyword opportunities from the Competitor Gap Report (high demand, weak competition)
- Prioritize topics the client can produce quickly (existing knowledge, no new research needed)
- Deliver quick wins from the Channel Audit Report (improve top 5 existing videos)
- Establish consistent upload cadence (this matters for the algorithm)

### Phase 2 — Acceleration (Days 31–60)
**Goal**: use Phase 1 performance data to double down on what's working.

Focus:
- Identify the 2–3 topics or formats from Phase 1 that outperformed
- Build on those angles (sequels, deeper dives, adjacent topics)
- Introduce 1–2 new keyword targets from the opportunity list
- Begin building the first content cluster for playlist structure

### Phase 3 — Optimization (Days 61–90)
**Goal**: refine the strategy based on 2 months of real data.

Focus:
- Full performance review: what's driving search traffic vs. browse traffic?
- Identify the channel's "content pillars" — the 3–5 topic types that consistently perform
- Design the next 90-day plan based on confirmed pillars
- Set growth targets for the next quarter

## Content Calendar Design

A content calendar gives the client visibility and the agency accountability.

### Calendar Structure
For each planned video, document:
- Target publish date
- Working title (or 2–3 title options)
- Primary keyword target
- Topic category / content pillar
- Production status (briefed / in production / QC review / ready)
- Priority level (high opportunity vs. regular cadence)

### Upload Cadence Rules
Consistency matters more than frequency. A channel that uploads once per week reliably outperforms one that uploads 3 times one week and goes quiet for 2 weeks.

Recommend based on client capacity:
- **Minimum viable cadence**: once per week (non-negotiable for algorithm momentum)
- **Growth cadence**: 2–3 times per week
- **Aggressive growth**: 4–5 times per week (only recommend if client has production capacity)

## Workflow Orchestration

As CSO, the content strategy skill also covers managing the team workflow:

### New Client Trigger Sequence
```
1. Niche Intelligence Analyst → Niche Profile
2. Audience Persona Builder → Persona Card
3. Competitor Analyst → Gap Report
4. Channel Auditor → Audit Report
5. Brand Voice Specialist → Voice Profile
6. CSO review → approve all outputs
7. CSO → design 90-day content strategy
8. Strategy briefed to Production Team
9. Production begins
```

### Per-Video Trigger Sequence
```
Client confirms topic
→ Competitor Analyst: Per-Video Brief
→ Keyword Researcher: Keyword Brief
→ Title Copywriter: Title Set
→ Description Writer: Description Draft
→ Tags Specialist: Tag Set
→ Chapter Architect: Chapter Set
→ Thumbnail Strategist: Thumbnail Brief
→ Quality Controller: QC Review
→ Client delivery
→ Community Engagement Strategist: Engagement Package
→ Cross-Platform Repurposing Agent: Repurposing Package
→ Playlist Architect: Per-Video Architecture Note
→ Client Reporting Agent: log all outputs
```

### Strategy Adjustment Trigger
```
Performance Analyst flags sustained underperformance
→ CSO reviews flagged metrics and identifies cause
→ CSO adjusts: keyword targets / content mix / upload cadence / format
→ CSO briefs Production Team on adjusted direction
→ CSO notifies CEO if client is at risk
```

## Handoff

90-Day Strategy → CEO for approval
90-Day Strategy → Production Team for briefing
Strategy adjustments → Production Team + Client Reporting Agent (for context)
